# Python & MySQL Projects

A collection of Python programming and MySQL database projects developed as part of practical learning and coursework.

## 📂 Projects

### 01. Student Performance Analysis

Analyzes student marks using **Python, NumPy, and Pandas**.

**Topics covered:**

* Total and average marks
* Subject-wise analysis
* Highest and lowest marks
* Pass/fail analysis
* Standard deviation
* DataFrame operations

### 02. Student Attendance Analysis

Analyzes student attendance using **Python, NumPy, and Pandas**.

**Topics covered:**

* Student-wise attendance
* Subject-wise attendance
* Highest and lowest attendance
* Attendance eligibility
* Average and standard deviation
* DataFrame operations

### 03. Education Data Analysis

Analyzes education-related data using **Python, Pandas, NumPy, and Matplotlib**.

**Topics covered:**

* School enrollment analysis
* District-wise comparison
* Gender-wise analysis
* Class X and XII pass percentage
* Schools vs performance
* Data visualization

### 04. Academic Performance Analysis

Analyzes academic performance across multiple semesters using **Python, NumPy, Pandas, and Matplotlib**.

**Topics covered:**

* Semester-wise performance
* Subject-wise averages
* Target analysis
* Class average comparison
* Performance visualization

### 05. ATM Simulator

A console-based ATM simulation developed using **Python**.

**Features:**

* Account creation
* User login
* Balance inquiry
* Deposit
* Withdrawal
* Mini statement
* ATM menu system

### 06. Employee Management SQL

A MySQL project for managing employee information and performing database queries.

**Topics covered:**

* Database and table creation
* Insert, update, and delete operations
* Filtering and sorting
* Aggregate functions
* Grouping
* Employee analysis queries

### 07. Banking System SQL

A MySQL database project that models a basic banking system.

**Includes:**

* Branches
* Customers
* Accounts
* Cards
* Transactions
* Relational database design
* SQL queries and analysis
* Window functions

## 🛠️ Technologies Used
